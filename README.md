# WithEar (인이어 메트로놈 동기화 웹 시스템)

같은 방 번호로 접속한 밴드/세션 멤버들이 그룹장이 세팅한 6개의 프리셋(고정 BPM / 가변 구간별 평균 BPM 및 마디수)을 동시에 똑같은 인이어 메트로놈 박자로 듣는 웹 애플리케이션입니다.

## 주요 기능

1. **깔끔한 3버튼 홈 화면**
   - **방 만들기**: 닉네임을 입력하고 4자리 방 번호를 생성하여 그룹장(Host)으로 입장합니다.
   - **방 접속하기**: 4자리 방 번호와 닉네임을 입력해 팀원들과 같은 인이어 메트로놈 방에 접속합니다.
   - **프리셋 설정**: 6개의 프리셋 슬롯을 직접 탭(Tap)하면서 고정/가변 BPM 및 마디수를 세팅합니다.

2. **프리셋 설정 (직접 탭하여 고정/가변 구간별 평균 BPM 계산 & 마디수 선택)**
   - **6개 프리셋 슬롯 (`PRESET 01` ~ `PRESET 06`)** 저장 지원
   - **고정 BPM 모드**: 탭 패드(또는 `Space` 키)를 연속으로 두드리면 탭 간격의 **평균 BPM**이 실시간 계산되며, 연주할 **마디수 (`∞ 무제한`, `4`, `8`, `16`, `32`마디 또는 직접 입력)**를 선택할 수 있습니다.
   - **가변 BPM 모드**: 곡의 구간(예: 인트로 → 벌스 → 후렴)을 여러 개 추가하고, 각 구간을 클릭한 뒤 탭 패드를 두드려 **구간별 평균 BPM**을 계산해 저장하며 각 구간의 **마디수(Bars)**를 설정할 수 있습니다.

3. **인이어 방 화면 (실시간 접속자 표시 + 대형 프리셋 & PLAY 버튼)**
   - **상단 접속자 표시**: 방에 들어온 멤버들의 닉네임과 실시간 박자 동기화 상태 LED가 상단에 표시됩니다.
   - **중앙 프리셋 & 대형 PLAY 버튼**: 현재 선택된 프리셋의 이름, 초대형 BPM, 현재 마디/전체 마디(가변 BPM일 경우 현재 구간 정보 포함), 4박자 시각 LED 및 대형 **PLAY / STOP** 버튼이 중앙에 배치됩니다.
   - **하단 6개 프리셋 선택 패드**: 방 안에서 6개의 프리셋을 즉시 전환하여 모든 접속자에게 동기화합니다.

## 실행 방법

```bash
npm start
# 기본 포트: http://localhost:3000
```
